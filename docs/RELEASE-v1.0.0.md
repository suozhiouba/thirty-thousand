# 三万 · 时间账户 v1.0.0

把时间，当作唯一的本金。

首个 Android 体验版本：以三万天为统一刻度，将剩余时间显示为持续流动的余额，每天留下一条自己的时间账单。

## 包含功能

- 生日设置、时间币余额与天 / 时 / 分 / 秒 / 毫秒倒计时。
- 300 格人生刻度与今日时间流水。
- 每天唯一留言、草稿保存、历史查看与搜索。
- HTTPS 双来源校时与离线时间估计。
- 本地 JSON 备份导出与恢复。

## 安装

下载下方附件 `thirty-thousand-1.0.0.apk`，在 Android 8.0 或更新版本手机上打开安装。

当前 APK 使用开发签名。生日与留言仅保存在本机，卸载前请导出备份；备份文件是明文，请妥善保管。

三万天不是寿命预测。毫秒为显示刻度，联网校时仍可能存在秒级误差。
